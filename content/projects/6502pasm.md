title="6502 Portable Assembler"
+++

This is just a tiny 6502 assembler I made. It's "portable" bc it just uses C++ standard libraries and doesn't interact with the OS besides memory allocation and printing. It's also only a header and single source file.

I made it so I could make a 6502 emulator/programmer/debugger for the M5Stack Cardputer, but I never finished that.

Source code is [here](https://github.com/calsch/6502pasm) (be warned, the README is quite bad)
